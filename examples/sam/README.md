# Example: Sam

A fictional person, to show what Life OS looks like after `/life-architect`.
Sam is 29, has ADHD, works in customer support, is studying for a cert, and
shares a flat. Only the three core files are shown; a real setup also has
`areas/` folders and an "About the person" section in `AGENTS.md`.

What `/life-architect` picked up and designed around:

- Every past system (Notion, bullet journal, two apps) died after one missed
  day, because the backlog felt like a judgment. → Fresh start rule; no
  overdue list; Now capped at 2.
- Sharpest 10:00–13:00 on days off; crashes after 16:00 on shift days. → Study
  goes in the morning on days off; shift days have 1 Now item.
- Admin (bills, forms) only gets done with someone around. → Sunday admin hour
  on a call with a friend.
